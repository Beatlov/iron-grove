# HELIOS H37: повторяемые проверки баланса

Запуск из корня, Node без зависимостей:

```sh
node scripts/balance-report.cjs
node scripts/supply-report.cjs
node scripts/combat-report.cjs
node scripts/power-report.cjs
node scripts/crystal-access-report.cjs
node --test tests/*.test.cjs
```

Все сценарии детерминированы по игровому seed; реальные CPU-тайминги зависят от машины и нагрузки. Для нового сравнения сохраняйте JSON рядом с текущими отчётами. Шаблоны используют готовые базы, а не моделируют решения игрока по развитию. Добавленный рецепт автоматически участвует в таблице спроса, но новые здания/механики могут потребовать расширения промышленных сценариев.

- `h34-baseline.json`: исходная H34 до изменений, добыча газа/серы 90/72 в минуту на станцию с двумя работниками. Теоретический спрос рецептов, неизменяемый снимок военных цен/времени/содержания, реальные 30-минутные добывающие колонии 1/3 планет.
- `h35-economy.json`: тот же шаблон на H35, добыча 54/42. Склад 5000; готовые источники/станции/перевозчики и конечные тестовые запасы еды/минералов/токенов. Первое заполнение одиночной колонии 849,2 → 1506,8 с; три колонии почти полны к 30 минутам даже после замедления. `firstFull` — первое одновременное заполнение всех складов, не обещание, что затем свободного места никогда не появится из-за содержания.
- `h35-supply.json`: 15 минут, все шесть цехов, добыча, биопристройки, шесть перевозчиков, казарма на колонию. 10 000 еды/токенов и большие склады — только условия замера сырья/доставки. Набор сценариев: без армии, с реальными очередями армии, одна/три колонии. При обучении используется прежний режим цехов «по необходимости», при мирном выпуске — до заполнения. Старые/новые скорости сравниваются на одном H35-коде, чтобы выделить именно коэффициенты добычи. Контрольная пара выпуска бойцов: 8/10 на одной колонии, 36/33 на трёх. Разные запасы газа при меньшей добыче отражают загрузку транспорта/рецептов, а не дублирование ресурсов. Это не расчёт самодостаточной экономики 100 бойцов или универсального «идеального баланса».
- `h35-combat.json`: 50/100 на сторону, все пять человеческих классов, seed7/42/98, настоящий движок с тактом50ms, без Canvas. Проверены завершение, конечные координаты/HP, отсутствие рангов и предел эффектов; подробная проверка препятствий/повторяемости также в тестах. Тайминги — CPU на машине запуска, не FPS.
- `h35-browser.json`: настоящая Chromium-проверка 100×100 с рисованием, паузой/повтором и изоляцией, 100 бойцов в кампании, оборона с наймом, пять размеров. Время ручного шага включает симуляцию/Canvas/UI, но не является замером стабильного экранного FPS. Прямой file:// блокируется политикой этой среды; HTTP и уже загруженная игра без сети проверены.

Полные правила/цены/ограничения — [GAME_GUIDE.md](../GAME_GUIDE.md). При расширении контента повторите добычу, действующее производство и бои вместе; не замедляйте все базовые ресурсы по одному изолированному замеру.

## Электричество H36

`h36-power.json` выводит бюджет газа из текущих рецептов и эффективности газовой электростанции:54/мин добыча,37/мин цехи,12/мин полный источник100МВт,5/мин остаток. Два полных источника+цехи61/мин требуют расширения. Добыча не увеличена. Топливо следует реальной нагрузке после обычной генерации, в резерве не сжигается.

Четыре промышленных прогона15мин:1/3 колонии, три обычных генератора (сеть140МВт) против одного обычного+газового (до160МВт). Газовый инвентарь изначально пуст, топливо возят настоящие дроны. Подготовленные здания, оборотная еда/токены и увеличенные тестовые склады — условия прежнего сценария, не стартовые бонусы игроку. Обучение использует текущие цены и режим цехов по необходимости. Обычные схемы обучили10/33 бойца, газовые6/34; последние сожгли4,9094/16,477 газа суммарно. Схемы имеют разную мощность и запуск, это не универсальное сравнение эффективности баз. Итоговые сети без отключений, источники газа в резерве; пиковые и средние значения нельзя подменять друг другом.

`h36-browser.json`: UI-строительство/питание/приоритеты/реальный газ/разные планеты/пять размеров. `h36-regression.json`:100v100/рисование/пауза/повтор/изоляция,100-unit кампания/результат/оборона.256 Node-тестов включая9 энергетических. Старые H34/H35 JSON — исторические результаты; текущие сценарии учитывают электричество. Прямое file:// блокируется политикой среды; HTTP и загруженная офлайн-игра проверены.

## H37: два кристальных генератора и доступ со всех сторон

Текущие генераторы: малый40МВт/.001 кристалла на МВт·с (2,4/мин максимум), большой100/.0015 (9/мин). Ядро20 бесплатно. Газ для электричества0; все рецепты газа37/мин при добыче54. Все рецепты кристаллов64,29/мин; с малым66,69, большим73,29, обоими75,69. Стоимости/таймеры войск и добыча не менялись. Большой дороже и потребляет больше на полной мощности; малые приоритетнее при распределении нагрузки.

`h36-crystal-baseline.json` снят до изменения доступа, `h37-crystal-access.json` — после, те же подготовленные схемы:60с разогрев+300с замер,2 работника и2 достижимые залежи. Добыча близко86,4/мин, с дорогами102,4, дальше с дорогами70,4. Итог не обещает ту же производительность при одной залежи/произвольной логистике. Окно доставки может включать груз из разогрева, поэтому не обязано численно совпадать с добычей. Скорости не увеличены.

`h37-power.json`: четыре15-минутных прогона одной/трёх колоний с реальными цепочками и пустыми топливными запасами. Малая схема3 малых источника, смешанная1 малый+1 большой, генераторы ближе к базе, пополнение партиями. Предподготовленные здания/крупные склады/10k еды и токенов — тестовые условия, не бонус игроку. Обучено1/19 и3/30 бойцов; сожжено24,4311/76,4908 и29,26765/90,6168 кристалла соответственно. Итоговые потребители запитаны, но не все источники обязательно имеют топливо. Разная мощность/резерв/доставка/конфигурация делают результаты непригодными для универсального сравнения баз. Добыча/цены войск прежние.

`h37-browser.json`: плюс без покупки, касающиеся дома, удалённые соседние биопристройки/урожай, строительство/доставка/расход двух генераторов и5 размеров. `h37-regression.json`: массовые бои/кампания/оборона/полигон.267 Node-тестов включая11 новых сценариев. Старые H34–H36 JSON остаются историей; текущие скрипты работают по H37. Газовые бюджеты H36 не являются текущими правилами.
