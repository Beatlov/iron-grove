# HELIOS H35: повторяемые проверки баланса

Запуск из корня, Node без зависимостей:

```sh
node scripts/balance-report.cjs
node scripts/supply-report.cjs
node scripts/combat-report.cjs
node --test tests/*.test.cjs
```

Все сценарии детерминированы по игровому seed; реальные CPU-тайминги зависят от машины и нагрузки. Для нового сравнения сохраняйте JSON рядом с текущими отчётами. Шаблоны используют готовые базы, а не моделируют решения игрока по развитию. Добавленный рецепт автоматически участвует в таблице спроса, но новые здания/механики могут потребовать расширения промышленных сценариев.

- `h34-baseline.json`: исходная H34 до изменений, добыча газа/серы 90/72 в минуту на станцию с двумя работниками. Теоретический спрос рецептов, неизменяемый снимок военных цен/времени/содержания, реальные 30-минутные добывающие колонии 1/3 планет.
- `h35-economy.json`: тот же шаблон на H35, добыча 54/42. Склад 5000; готовые источники/станции/перевозчики и конечные тестовые запасы еды/минералов/токенов. Первое заполнение одиночной колонии 849,2 → 1506,8 с; три колонии почти полны к 30 минутам даже после замедления. `firstFull` — первое одновременное заполнение всех складов, не обещание, что затем свободного места никогда не появится из-за содержания.
- `h35-supply.json`: 15 минут, все шесть цехов, добыча, биопристройки, шесть перевозчиков, казарма на колонию. 10 000 еды/токенов и большие склады — только условия замера сырья/доставки. Набор сценариев: без армии, с реальными очередями армии, одна/три колонии. При обучении используется прежний режим цехов «по необходимости», при мирном выпуске — до заполнения. Старые/новые скорости сравниваются на одном H35-коде, чтобы выделить именно коэффициенты добычи. Контрольная пара выпуска бойцов: 8/10 на одной колонии, 36/33 на трёх. Разные запасы газа при меньшей добыче отражают загрузку транспорта/рецептов, а не дублирование ресурсов. Это не расчёт самодостаточной экономики 100 бойцов или универсального «идеального баланса».
- `h35-combat.json`: 50/100 на сторону, все пять человеческих классов, seed7/42/98, настоящий движок с тактом50ms, без Canvas. Проверены завершение, конечные координаты/HP, отсутствие рангов и предел эффектов; подробная проверка препятствий/повторяемости также в тестах. Тайминги — CPU на машине запуска, не FPS.
- `h35-browser.json`: настоящая Chromium-проверка 100×100 с рисованием, паузой/повтором и изоляцией, 100 бойцов в кампании, оборона с наймом, пять размеров. Время ручного шага включает симуляцию/Canvas/UI, но не является замером стабильного экранного FPS. Прямой file:// блокируется политикой этой среды; HTTP и уже загруженная игра без сети проверены.

Полные правила/цены/ограничения — [GAME_GUIDE.md](../GAME_GUIDE.md). При расширении контента повторите добычу, действующее производство и бои вместе; не замедляйте все базовые ресурсы по одному изолированному замеру.
