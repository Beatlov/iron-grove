# Железная роща · прототип RTS 0.1

Небольшая одиночная 2D RTS для компьютера с мышью и клавиатурой. Пиксельная графика рисуется кодом. Игра полностью локальная: без установки пакетов, сервера, аккаунтов и интернета.

## Запуск

Распакуйте весь архив. Откройте `index.html` в настольном браузере. Сохраните `engine.js`, `game.js` и `style.css` рядом с ним. Рекомендуемая ширина окна — от 1100 пикселей.

## Первая партия

1. Выделите трёх рабочих над синей базой рамкой левой кнопкой мыши.
2. Нажмите правой кнопкой по деревьям на северо-западе. Рабочие начнут добычу и будут относить дерево на базу.
3. Нажмите B или «Построить казарму». Поставьте её на зелёном свободном участке рядом с базой. Стоимость — 120 дерева. Строительство в прототипе мгновенное, требует наличия рабочего.
4. Выделите казарму и нажимайте «Нанять: Боец». Выделенная база позволяет нанимать рабочих. Очередь — до пяти юнитов.
5. Соберите бойцов рамкой, двигайтесь через проход в скалах. Правая кнопка по красной базе — атаковать.
6. Защитите свой штаб: первая волна придёт через 55 секунд, следующие — каждые 45 секунд. Уничтожение вражеской базы приносит победу, потеря своей — поражение.

ЛКМ — выделение; рамка — выделить отряд; Shift — добавить к выделению; ПКМ — приказ; B — казарма; Esc — отменить размещение; пробел — пауза. При переключении окна игра встаёт на паузу.

Начальный запас — 160 дерева. Рабочий: 40 дерева / 4 секунды, боец: 70 / 6 секунд. Вместимость рабочего — 20 дерева.

## Исходники и Codex

Это обычный проект без зависимостей. Откройте распакованную папку `iron-grove` в редакторе или в рабочей среде Codex. `AGENTS.md` описывает архитектуру и ограничения; `ROADMAP.md` — следующие этапы. Проект не привязан к этому чату.

- `engine.js` — симуляция: карта, поиск пути, приказы, добыча, производство, волны, бой и исход партии. Не зависит от DOM.
- `game.js` — Canvas-отрисовка, управление мышью и клавиатурой, интерфейс.
- `style.css`, `index.html` — оболочка игры.
- `tests/` — проверки симуляции и интеграционная проверка интерфейса с имитацией DOM. Запуск при установленном Node.js: `node --test tests/*.test.cjs`. Имитация DOM не заменяет визуальную проверку в настоящем браузере.

## Границы первой версии

Это браузерный прототип для проверки игры, а не самостоятельный `.exe`. Нет сохранений, мультиплеера, тумана войны, звука и редактора карт. Юниты могут проходить друг через друга. Выбрана одна небольшая карта целиком на экране, без прокрутки. Вражеская база получает подкрепления по таймеру, без собственной экономики. Баланс предварительный.

Для отдельного приложения потребуется упаковка или перенос в настольный игровой движок. Перенос не сделан автоматически; код симуляции и правила отделены от визуального слоя, чтобы дальнейшая работа была понятной.
