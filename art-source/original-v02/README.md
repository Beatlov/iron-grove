# Просмотр оригинальных PNG · v02

4 ноября 2026 года. [Основная страница просмотра](../preview.html) теперь берёт изображения **напрямую из пользовательских оригиналов** в `docs/design/worker-source-v01`. Они не уменьшались, не перекрашивались, не получали новый контур или порог прозрачности. Никаких новых PNG для этой версии не создаётся. К игре изображения пока не подключены.

## Что меняется только при показе

- Manifest задаёт 256 прямоугольников исходных кадров, их исходные точки опоры и порядок восьми направлений. Разметка отделяет кадры, сохраняя исходные отступы и полупрозрачные края.
- Внутри Canvas исходный прямоугольник копируется **один к одному**, без изменения размеров. Общее окно 384×384 с опорой (192,272); это окно предпросмотра, не новый размер игрового юнита и не новый PNG.
- Масштабы 50/100/200% и «около размера в игре» изменяют только CSS-размер отображения. При 100% и достаточной ширине окна виден исходный пиксель один к одному. На узком экране браузер может дополнительно вписать окно просмотра.
- Опциональные граница кадра и крестик опоры — отдельный слой просмотра; по умолчанию выключены.
- Главное здание показывается непосредственно из исходного PNG 1303×1207. Размер 96×96 остаётся будущим игровым ориентиром, но файл к нему здесь не приводится.

Файлы: [manifest.json](manifest.json), [frames.js](frames.js), [validation.json](validation.json), [browser-validation.json](browser-validation.json). JSON и JS содержат одинаковые данные; JS нужен, чтобы просмотр не требовал fetch и оставался статической страницей с локальными файлами.

## Проверки

`python3 scripts/map-original-sprites.py` создаёт только координатные метаданные; `python3 scripts/check-original-sprites.py` сверяет исходные SHA-256, размеры PNG, 256 записей, разбиение листов без пропусков/перекрытий и размещение без обрезания. Для этих двух скриптов достаточно стандартного Python, пакеты обработки изображений не нужны.

В Chromium каждый из 256 кадров сравнен попиксельно с отдельным прямым чтением той же области исходного PNG: совпадение полное. Это сравнение одинакового браузерного декодирования RGBA, а не обещание отсутствия особенностей цветового управления браузера. Проверены пауза, шаг, повтор, переключение действий/масштабов и удержание последнего кадра гибели. Обработанные PNG v01 просмотрщик не загружает.

## Что остаётся от оригинала

Различия между исходными позами, инструментами, ракурсами и масштабами разных листов не исправляются. Привязки приблизительно выравнивают шлем/линию земли; внутри поз сохраняется движение. При гибели некоторые исходные кадры меняют направление относительно первой позы ряда. Поэтому отсутствие обработки не гарантирует идеальную авторскую анимацию, но исключает прежнее изменение цветов/деталей/прозрачности.

[Обработанный вариант v01](../preview-processed-v01.html) оставлен как архив для сравнения. Его атласы не являются текущим рекомендованным способом просмотра. Для будущего подключения использовать эти координаты и оригинальные PNG; графика игры в этой работе не менялась.
