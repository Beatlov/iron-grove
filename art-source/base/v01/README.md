# Командное ядро v01

Архив обработки: актуальный [просмотр оригинала v02](../../original-v02/README.md) показывает исходное изображение ядра без изменения пикселей. Этот вариант 96×96 сохранён для сравнения.

Изображение здания из архива пользователь подтвердил как **главное здание / командное ядро (`base`)**. Подготовлено 4 ноября 2026 года, **к игре не подключено**.

- [idle.png](idle.png): **96×96 px**, 4×4 игровые клетки по 24 px, точка привязки в центре **(48,48)**.
- Одна статичная поза; бинарная прозрачность, общая фиксированная палитра, однопиксельный тёмный контур.
- Объект с бетонными площадками целиком внутри кадра с прозрачным запасом по краям. Прозрачные разрывы сохранены, сплошной квадратной подложки нет. Декор не выходит в соседние дорожные клетки.
- Обрезано только пустое пространство вокруг исходника, масштаб равномерный, без искажения пропорций. Исходный крупный PNG не изменён.

[Увеличение ×8](preview-x8.png), [метаданные и SHA-256](manifest.json), [общий предпросмотр](../../preview.html).

Рабочее состояние, этапы строительства, повреждение и альтернативные виды не поставлялись. У исходного здания выделен фасадный вход; при подключении это не должно ограничить существующий доступ рабочих/дронов с четырёх сторон. Перспектива, круглая форма и окружение сохранены из присланного рисунка, архитектура не перерисована.

Обработка/проверка: `scripts/prepare-sprites.py`, `scripts/check-prepared-sprites.py`. Нужные пакеты только для подготовки, без новых зависимостей игры.
